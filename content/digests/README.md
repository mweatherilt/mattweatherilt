# Digests

Daily Digests are named `YYYY-MM-DD.md`. Frontmatter `date` and `slug` match that day.

These are social-pulse catch-ups only — not YouTube transcripts.

Public routes: `/digests/YYYY-MM-DD/`. Homepage signal and listing update after each daily file.

Create-only: add a new day file, or update today's file in place. Do not delete Digests.
